2. Explain it in your own words.

4. Test it with different inputs.
5. Record errors, fixes, and what you learned.

## Day 1 — Variables, data types, operators, conditions and loops

### Learning objectives
- Explain the difference between `let` and `const`.
- Identify JavaScript primitive and reference data types.
- Use arithmetic, comparison, and logical operators.
- Make decisions with `if`, `else if`, and `else`.
- Repeat actions with `for` and `while` loops.
